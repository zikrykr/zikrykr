# Zikry Kurniawan

Senior Backend Engineer based in Tangerang, Indonesia (originally from Klaten, Central Java).

I've spent the last 7+ years building backend systems — mostly in Go and TypeScript. Most of my work has been around APIs, microservices, and event-driven services: the kind of systems that start from a business requirement and end up running in production. These days I'm spending a lot of time on distributed systems, performance, and observability, and I run a small side lab (JikurLabs) for experiments and SaaS ideas.

A few opinions I've picked up along the way: keep systems simple until they actually need to be complex, measure before optimizing, and write tests as you go rather than bolting them on later.

## Where I've worked

**Sprout Digital Labs** — Senior Backend Engineer (2025–present)
Owning authentication, payments, inventory, and permissions. Built a Redis-backed session auth system, integrated Xendit for payments, and moved a chunk of inter-service traffic onto RabbitMQ to cut coupling. Permission checks are cached in Redis now, and test coverage sits above 80%.

**eFishery** — Backend Engineer (2022–2025)
Backend services in Go across order management, buyer management, and promotions — REST, gRPC, and GraphQL. Built event-driven flows on RabbitMQ, automated order confirmation against Odoo ERP, and wired up WhatsApp ordering through Yellow.ai.

**TaniFund** — Backend Engineer (2021–2022)
Farmer project management systems, integrations with national banking APIs, and the repayment/funding workflows behind them.

**Sprout Digital Labs** — Software Engineer (2019–2021)
Node.js + MySQL backends and a handful of payment-gateway integrations for client projects.
